# czujnik_cofania_arduino
Czujnik informujący o odległości od obiektu poprzez zapalanie odpowiedniej diody oraz zmiana wydawanego dzwięku. Instnieją 4 tryby: zielony - bezpieczny, pomaranczowy - zblizanie, czerwony - niebezpieczeństwo  oraz  biały - blisko uderzenia. Z każdym z nich zmienia się również dzwięk, co jest kolejną formą ostrzeżenia.
